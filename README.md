# Приказ о создании НФГО (ASP.NET Core Web API)

Прототип для задания по ГО: **«Приказ о создании НФГО — автоматическое формирование приказа и привязка его к сотрудникам, ролям и СИЗ»**.

Проект сделан в том же стиле, что и `SizCardAPI` (карточка учёта СИЗ): те же стек и слоистая архитектура.

## Что делает система

1. В справочниках ведутся **сотрудники**, **формирования НФГО** (спасательное звено, санитарный пост…), **виды СИЗ** и **роли** (командир, спасатель, санитар…).
2. Для каждой роли задаются **нормы СИЗ**: сколько единиц какого СИЗ положено человеку в этой роли.
3. Сотрудник **назначается** в формирование с определённой ролью (один сотрудник — одно назначение).
4. Кнопка/метод **«Сформировать приказ»** автоматически собирает приказ: участников, их формирования и роли, а СИЗ подтягивает по нормам роли. Считается общая потребность в СИЗ.
5. Приказ выгружается в **Word (.docx)** — готовый текст с таблицей личного состава, таблицей потребности в СИЗ и подписью руководителя.
6. Приказ имеет статусы: **Проект → Подписан / Отменён**. Состав приказа — «снимок» на момент формирования: последующие изменения справочников подписанный приказ не затрагивают. Проект можно пересобрать по актуальным назначениям.

## Стек

- ASP.NET Core 8 Web API (controllers)
- Entity Framework Core + SQLite (файл `nfgo.db` создаётся автоматически)
- DocumentFormat.OpenXml — генерация `.docx`
- Swagger UI
- Фронтенд на чистом HTML/CSS/JS в `wwwroot/`

## Архитектура

```
Controller  →  Service (интерфейс)  →  Repository (интерфейс)  →  AppDbContext → SQLite
```

- `Controllers/` — тонкие контроллеры, зависят только от интерфейсов сервисов.
- `Services/OrderService` — главная логика: формирование приказа, статусы, правила (подписанный не удалить и не пересобрать).
- `Services/OrderDocumentBuilder` — построение Word-документа.
- `Services/AssignmentService`, `RoleService`, `CrudService` — назначения, роли с нормами, простые справочники.
- `Repositories/` — интерфейсы (`IRepositories.cs`) и EF-реализации (`EfRepositories.cs`).
- `Common/Exceptions.cs` — доменные исключения и middleware, переводящий их в 404 / 409 / 400 с телом `{ "error": "..." }`.
- `Models/`, `DTOs/`, `Data/` — сущности, DTO, контекст БД и демо-данные.

## Как запустить

Нужен **.NET 8 SDK** (`dotnet --version` → 8.x).

```bash
cd NfgoOrderApi
dotnet restore
dotnet run
```

- `http://localhost:5001/` — веб-интерфейс
- `http://localhost:5001/swagger` — Swagger UI

При первом запуске создаётся база и загружаются **демо-данные** (вымышленные сотрудники, роли, нормы). Отключить: `"SeedDemoData": false` в `appsettings.json`. Чтобы начать с чистой базы — удалите файл `nfgo.db`.

## Эндпоинты

| Метод | Путь | Что делает |
|-------|------|-----------|
| GET/POST | `/api/employees` | Сотрудники |
| GET/PUT/DELETE | `/api/employees/{id}` | |
| GET/POST | `/api/units`, `/api/units/{id}` | Формирования НФГО |
| GET/POST | `/api/siz-types`, `/api/siz-types/{id}` | Виды СИЗ |
| GET/POST | `/api/roles` | Роли (с нормами СИЗ в ответе) |
| PUT | `/api/roles/{id}/siz-norms` | Заменить нормы СИЗ роли |
| GET | `/api/assignments` | Все назначения |
| GET | `/api/assignments/unassigned-employees` | Сотрудники без назначения |
| POST/PUT/DELETE | `/api/assignments[/{id}]` | Включить / изменить / исключить |
| GET | `/api/orders` | Список приказов |
| GET | `/api/orders/{id}` | Приказ с составом, СИЗ и итогами |
| POST | `/api/orders/generate` | **Автоматически сформировать приказ** |
| POST | `/api/orders/{id}/regenerate` | Пересобрать состав проекта |
| PATCH | `/api/orders/{id}/status` | Сменить статус (`Signed` / `Cancelled`) |
| GET | `/api/orders/{id}/document` | **Скачать приказ в Word** |
| DELETE | `/api/orders/{id}` | Удалить (кроме подписанного) |

## Пример: формирование приказа

```bash
curl -X POST http://localhost:5001/api/orders/generate \
  -H "Content-Type: application/json" \
  -d '{
    "number": "15-ГО",
    "orderDate": "2026-10-07",
    "organization": "ООО «Пример»",
    "headPosition": "Генеральный директор",
    "headFullName": "Иванов И.И."
  }'

curl -o prikaz.docx http://localhost:5001/api/orders/1/document
```

Ответ содержит приказ и список `warnings` (например: у роли не заданы нормы СИЗ, есть сотрудники без назначения).

## Важно

- Поле **«Основание»** по умолчанию содержит общую формулировку со ссылкой на ФЗ № 28-ФЗ «О гражданской обороне». Подставьте реквизиты актов из вашей методички/организации.
- Связь с `SizCardAPI`: приказ закрепляет СИЗ по видам (`SizTypeId`). Пункт приказа №5 поручает поставить выданные СИЗ на учёт в карточках — при желании можно связать виды СИЗ с карточками учёта.
